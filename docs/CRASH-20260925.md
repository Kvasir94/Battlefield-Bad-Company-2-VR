## Exit after native view lifecycle experiment - 11:35:09 UTC

Report: reports/native-trace-20260925-113502-307; copied with module map and
assessment into reports/crash-20260925-113509. The inactive native factory test
reported registration count 1 -> 2 -> 1, references 0 -> 1 -> 0, inactive flag,
owner identity and restored logical main-view list. It observed only three
native frames. At 11:35:06 the bootstrap returned 0 and the process was alive;
BC2 wrote a crash report at 11:35:09 and subsequently exited. That earlier
completion record is NOT evidence of sustained stability.

The recorded EIP 0x00401090 is BC2's int3/exit handler. Reported address
0x5059a7df maps to MSVCR80.dll+0x3a7df, immediately after the handler invocation
inside exported _purecall. Other reported entries include native destructors,
CRT exit cleanup and 0x00c51fd5 (following the executable startup's call to
imported exit). This is consistent with a pure-call failure during shutdown;
there is no reliable unwind or dump proving why shutdown began, or whether
our view test caused it. The user was asked whether they closed the game;
no answer was available at this checkpoint. Do not claim the mod was unrelated.

Further inspection found the base view constructor also AddRefs its request,
registers in request+0x14/+0x18, and invokes all world callback vtables at slot 7.
Destruction unregisters that list, releases the request, and invokes slot 8.
The main-view list roundtrip alone did not validate those callback effects or
their safe thread/frame boundary. The live factory experiment is quarantined
in BOTH Start-NativeTrace.ps1 and the injected probe entry. Do not re-enable it
solely because its local reference/list checks passed.

Start-NativeTrace now retains the process handle for a 15-second post-probe
observation, copies a newly changed crash XML and fails if the process exits or
writes a crash report. Read-only BC2Observe now collects the all-view list and
world create/destroy callback addresses with bounded, stable snapshots; this
extension builds but needs a new campaign process for live verification.
