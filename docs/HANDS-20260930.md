## Portable and native boundaries

`TrackedRig` calibrates each grip to its current native wrist in a current upright
body frame. Head orientation does not drive hand targets. Translation calibration
is separate from orientation: a head-height offset must not become a wrist-roll
lever arm. A test found and fixed that exact pivot error. Recenter, actor generation,
equipped weapon and skeleton changes recalibrate. Missing focus/head/grip tracking,
invalid matrices and controller translation discontinuities reject publication.

`ArmIk` solves bounded two-bone arms and retains native finger/twist descendants.
`RetargetRigSubtree` moves a validated attachment chain with its current internal
animation intact. BC2 supplies its named rig roles and weapon root, never Refractor
indices. The tested rig has 147 bones, 44 arm edits and 20 weapon-chain edits.
The current authored weapon-to-wrist transform is composed with the solved right
wrist; the weapon follows reach clamping too. The left wrist remains independent:
physical two-hand support/grabbing and finger-input animation are still unbound.

The BC2 body origin compensates only actual native roomscale displacement, using
the same reference and heading as the accepted camera/body-follow integration.
No teleport or second simulation is used.

## Native consumer and lifetime evidence

Static preferred executable VAs (not transferable engine constants): soldier skin
getters 0x875da0/0x875dd0 forward through virtual animation getter +0x160(-1) to
0x78b0a0. Character preparation 0x5f2860 calls them, then invokes 0x4044d0 at return
sites 0x5f2b32 and 0x5f2b73. The full 0xce-byte cdecl packer synchronously copies
64-byte padded source matrices to 48-byte 3x4 matrices in the native request arena.
It does not retain the source pointer. Discovery verifies both getter relationships,
call sites and every packer byte; the x86 ABI regression checks arguments, packing,
source preservation and its incidental advanced-source EAX return.

`Bc2RigPublication` intercepts only that owned actor/weak-reference call chain.
The original native animation palettes are never overwritten. A validated immutable
pose is copied into a private full palette; the original packer runs once per
native invocation and copies it to its own destination. Both current/previous
palette slots receive the same owned pose; `paired_copies` counts the second slot,
not an eye. The resulting native render packet is used by the existing stereo path.
Generation, weapon, space, original QPC deadline and exact source-byte checks guard
publication. Source changes and packed output bytes are checked after each copy.

The weapon-world getter at 0x78b080 also has a verified caller-owned output from
animation update 0x8ade10 (return +0x85). After the original getter, only that output's
12 xyz components are replaced, preserving padding. Native attachment-root/effect
consumers run normally once. This is a real output override, not a read-only probe;
those consumers return to their original transforms on the next unmodified native
update when tracking is unavailable/stale or hooks stop. No background restoration
writes are made into persistent animation memory. Changing this output alone did
not move visible gun geometry; the weapon bone subtree also had to enter the skin
palette. The corrected captures show the gun and wrist moving together.
