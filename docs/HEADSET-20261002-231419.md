## Offline changes after the test

The seated-magazine policy now transfers visual attachment to the gun while
the native reload completes. Releasing the left hand no longer hides the mag or
forces that hand into its insertion pose. Current owner, tracking, native cycle,
GunHold and per-eye publication checks remain; only a real native ammunition
receipt completes the reload. The old code fails the new consumer regression.

Weapon calibration must distinguish a changed weapon asset from a reused native
object address. The observed SPAS-to-AEK exchange reused an address; the new
equipment generation invalidates old attachments and publication authority
without resetting the player's anatomy or recentering. It does not grant AEK
manual reload, holster or other unverified profile support.

Visible belt supply starts with one SPAS shell at the existing pickup anchor,
only when current native reserve and idle prop ownership allow it. It represents
available supply, not an independently stored shell or the total reserve count.
Held/guided reload props and current native animation take priority. The shared
anchor/availability policy supports other ammo families, but visible XM8 belt
magazines still need an independent render instance. The gun's existing magazine
must not be reused simultaneously as belt ammunition.

Complete development builds pass 123/123 tests on both architectures. These
repairs are offline tested; no new native or headset run was performed while
the user tested BF2142. The original preview4 ZIP and its recorded evidence remain
