## 17:40 update: native roomscale body-follow candidate

Use `Start-BC2VRSession.ps1 -BodyFollow` for the continuous first headset check.
BodyFollow includes MotionAim, controller actions and upright roomscale tracking.
All remain opt-in; the accepted rendering-only launcher defaults are preserved.

RoomscaleFollow is portable feedback: request on-foot motion outside a 12 cm
horizontal lean radius, observe actual native displacement, and consume only
that displacement from the camera's physical offset. Native collision remains
in charge. Ordinary joystick movement takes priority and is not subtracted.

feedback; owner/reference changes reset it. Tracking loss suspends drive.
BC2 supplies its live body position through the signature-verified af80c0/d46380
chain and its already validated input cache; no physics position writes occur.
