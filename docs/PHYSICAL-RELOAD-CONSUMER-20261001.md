Physical reload consumer candidate — 2026-10-01

The explicit `-PhysicalReload` / `--physical-reload` option sets bit `0x2000000` and connects the actual Gameplay gather path to body-pouch ammo supply, existing hand arbitration, SPAS insertion geometry, ManualReload, the BC2 request bridge, and the native request-cycle runtime. The mode is off by default. Normal launcher defaults are unchanged. Native and headset acceptance are not established.

The left pouch is a configurable head-yaw-relative comfort anchor at (-0.23, -0.55, +0.02) metres with an 18 cm pickup radius. A released-to-pressed left grip edge acquires a shell only with genuine idle reserve, exact selected SPAS mesh and rig, and the current right GunHold. It cannot steal support/sight ownership. The body-pouch data is a policy choice, not a discovered game socket. Other weapons retain their ordinary Reload action.

Acquisition starts a genuine native cycle and a 100 ms ordinary Reload input pulse. The same cycle continues between shells. Renderer N−1 contact is paired with its original immutable hand record and AmmoSupplySample; it is never relabelled as current geometry. Actual seating passes through ManualReload, bridge preparation and ReserveFrom before one native Submit. A native-confirmed acknowledgement plus matching post-ack count evidence consumes only the original reservation. Release or replacement does not consume a replacement shell. Full capacity or exhausted reserve cancels after settling the final receipt.

Carried presentation uses real idle reserve without inventing a held native cycle. Guided/pending poses require an actual held lease and original bounded geometry. Native hidden-shell state is not treated as virtual-item ownership; renderer shell visibility is a separate peer-owned candidate. Fire, use, equipment changes, focus/tracking/owner/space loss, failed cache commit, or stop cancels. Unknown pending state can retire only after the exact old native cycle is cancelled and drained, followed by a freshly observed reserve snapshot; it is not reported as consumed.
