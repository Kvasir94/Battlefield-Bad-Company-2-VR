# XM8 detachable-magazine candidate

**Current checkpoint (2026-10-02 05:13 UTC):** actual physical-consumer/native reload monitor passed with both GPU-eye images reviewed. See [XM8-MAGAZINE-MONITOR-CHECKPOINT-20261002.md](XM8-MAGAZINE-MONITOR-CHECKPOINT-20261002.md). Headset acceptance and combined SPAS/XM8/sight/holster regression remain pending; earlier staging-only statements below describe the original candidate stage.

This candidate composes the existing shared hand claims, AmmoSupply, ReloadInsertion and ManualReload policies. It adds no native ammo writes, no game assets, no native animation writes and no SPAS-specific behavior changes. It is disabled unless explicitly constructed with the separately verified magazine API. Native runtime currently chooses one family for an entire installation; switching SPAS/XM8 at runtime requires a separate retired-cycle family boundary.

## Interaction and authority

- A fresh eject edge requests UnseatMagazine. Alternatively, a fresh grip within 90 mm of the measured magazine wrist acquires the gun's dependent Mechanism claim; a continuous 90 mm outward pull removes it. Existing support/sight claims are never stolen. Removal starts only after actual neutral input.
- Unseat Applied comes only from the native adapter's fresh all-three-held gate receipt. It means reload is gated, not that loaded ammunition was subtracted. The old magazine is a cosmetic owned prop; releasing it does not replenish reserve or create a reusable partial magazine.
- After removal, an ordinary left squeeze at the configurable pouch acquires an existing AmmoSupply Magazine object. Its explicit cost is `min(capacity - loaded, reserve)`. The loaded remainder stays in BC2's pooled-round model.
- The keyed magazine acquires a 70 mm capsule around a 100 mm bottom-up rail within 45 degrees. It releases at 150 mm/75 degrees. Magnetic capture requires at least 35 mm new inward movement, 120 ms alignment and 60 ms dwell before one SeatMagazine request. A stationary starting pose at the socket, repeated timestamps or a tracking jump cannot seat it. These dimensions are deliberate UX defaults, not recovered engine socket metadata.
- Supply reserves the exact item/claim/seat/physical request/native cycle before one native Seat submission. Only the exact server-backed conserved transfer receipt resolves it. Time, pose, successful submission, unseat acknowledgement and animation are never completion evidence.
- Fire, alternate fire, equipment changes and native reload must be suppressed by Gameplay while detached; otherwise BC2 still has native loaded ammunition. Only `reloadHeld` emits the short native Reload pulse. After success/cancellation, a verified callback-drain receipt plus newly observed attached native magazine geometry and post-drain reserve are required to rearm. Pending unknown ammunition remains quarantined.
