includes fast free carry, wrist rotation and partial grip pressure. This is a
bounded native regression, not headset acceptance or all-weapon coverage.

## Shared fixes

- Extraction continuity limits stop applying after physical magazine removal.
  Both ordinary replacement and original-magazine return use the shared policy.
  Reinsertion still requires its keyed rail, travel, ownership and seat evidence.
- Reload grip uses the same release threshold as the hand arbiter. A fresh left
  Mechanism/AmmoObject claim may retain its grip between .35 and .75 squeeze;
  initial acquisition still requires .75. Release, stale ownership or lost tracking
  cannot borrow that retention. Magazine and shell sample producers share this rule.
- InputApplyRejected preserves already-committed empty-hands intent. Recovery
  still clears stale claims and requires fresh native suppression and paired
  visibility; it does not silently create a draw request.
- Cancellation logs now distinguish grip release, translation/rotation jumps,
  lateral departure and reverse extraction with measured values and limits.

The old headset trace directly proves the free-carry cancellation and unexpected
draw. Its second PullAbandoned event lacks enough detail to prove a particular
cause. Partial-grip premature release was independently reproduced against the
old threshold; it must not be presented as a proven explanation of that old event.
