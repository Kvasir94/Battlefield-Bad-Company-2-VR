#### Physical magazine reload (XM8)

- **Does:** the left hand pulls the magazine (`DetachableMagazine`), drops it,
  grabs a replacement from the pouch (`AmmoSupply`) and seats it. The native
  reload is started and held at state 11 by an exact delta override. On the
  seat it is fast-forwarded by the remaining state-11 timer, once per copy.
  The empty gate blocks auto-reload only at 0 loaded. A missed reserve read
  is retried at a quiet moment. Startup has a 750 ms read grace.
- **Evidence:** the XM8 one-launch scenario passed six or more consecutive
  runs: 085404, 085537, 085753, 085925, 092142, 092408, 110023.
  `gun-events.jsonl` scenario rules held, including timing. Reserve read
  acceptance went up about 5x (cf9d8ec).

  the XM8 (the AEK profile exists; the second-gun test is pending). A reserve
  of -1 (infinite) is rejected by the lease; treating it as an infinite pouch
  is deferred, because it touches about 260 reserve uses.

#### Reload sounds (F3)
