route from the actual item held. Direct selection still requires coherent repeated
native inventory/equipment evidence; unequal aliases retain their exact relationship
checks. Native ammunition transitions and launcher-sight admission are unchanged.

repair passes 85 focused groups per architecture and independent review.

stereo pair to the existing XR host. The host renders local installed geometry into

metadata leaves the native stereo images intact. It does not replay simulation or
change native scene rendering. Private depth handles the props themselves; native
